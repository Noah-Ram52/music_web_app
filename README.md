# Music Web App

## Front-end Music Web App
This project includes 3 different types of genres. The three types are Classical, Jazz, & Nerdcore genres. You can create and log in accounts in the back-end. You can also see the artists of the songs and information about them.

## User Implementation

In the backend there is user implementation using different types of requests. The following requests are sent to the database. In the [back-end](https://github.com/Noah-Ram52/music_web_app_express) you will be able to view it. This handles the data in the back for users and errors.
